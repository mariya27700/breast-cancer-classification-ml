# Breast Cancer Data Analysis and Visualization

## Introduction
This project focuses on Exploratory Data Analysis (EDA) and data visualization using the Breast Cancer Wisconsin Diagnostic dataset.

## Dataset
- Total Records: 569
- Numerical Features: 30
- Target Column: Diagnosis
- Classes: Benign (B) and Malignant (M)

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Visual Studio Code

## Visualizations
1. Diagnosis Distribution – Count Plot
2. Average Tumour Radius – Bar Chart
3. Tumour Area Distribution – Histogram
4. Tumour Perimeter Comparison – Box Plot
5. Tumour Radius vs Area – Scatter Plot
6. Feature Correlation – Heatmap
7. Compactness Distribution – Violin Plot
8. Selected Feature Relationships – Pair Plot

## Key Findings
- 357 benign samples and 212 malignant samples.
- The malignant group had higher average radius, perimeter, and area measurements.
- Mean radius and mean area showed a strong positive correlation of 0.987.
